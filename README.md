# 🕸️ IDR Web Spiders 

---

## 🏫 Project & Repository Description 

📘 **IDR (Informal Dataset Representation) for Web Spiders** is a technique used for **representing informal data in a compact form**. It includes an individual **W3C conformal personalized JSON dataset** representing the content of your public web page. This improves the quality of information sent to standard search engines. 

The system works with **Websites**, **Mobile Compatible Websites**, and **Standalone Mobile Compatible Websites**, leveraging public **Website Content**, **Canonical Tags**, **Meta Viewports**, and **HTTP Headers**. 

The goal is to help websites and SaaS applications improve their **search engine results** by providing a more accurate and tailored dataset to search engines.

## 🏫 Projekt- & Repository-Beschreibung 

📘 **IDR (Informal Dataset Representation) für Web Spiders** ist eine Technik zur **darstellung von informellen Daten in kompakter Form**. Sie beinhaltet ein **W3C-konformes, personalisiertes JSON-Dataset**, das den Inhalt Ihrer öffentlichen Webseite repräsentiert. Dies verbessert die Qualität der Informationen, die an standardisierte Suchmaschinen gesendet werden. 

Das System funktioniert für **Websites**, **mobile kompatible Websites** und **Standalone-Mobile-kompatible Websites** und nutzt **öffentliche Website-Inhalte**, **Canonical Tags**, **Meta Viewports** und **HTTP-Headers**. 

Das Ziel ist es, Websites und SaaS-Anwendungen zu helfen, ihre **Suchmaschinenergebnisse** zu verbessern, indem ein genaueres und maßgeschneidertes Dataset an Suchmaschinen übermittelt wird.
